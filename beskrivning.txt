Oliwer Carpman, Rafal Galinski, Robin Karim
Learning agent for curling

Problemformulering (Vilka AI relaterade problem ser ni initialt):

Problemet vi tänker göra är att bygga en applikationen sär en AI agent 
ska spela curling och lära sig desstu mer den spelar och försäka att kast 
sin stewn så att den hamnar så nära mitten på spelplanen som möjligt. 
Det ska finnas externa variabler som påverkar hur stenen kommer att agera 
efter att man har släppt den, det kan t.ex. vara vind, hastighet på isen 
eller hur andra sten ligger på isen innan den kastar. 

Förslag till möjliga lösningar strategier / AI tekniker

Vi tänker att lösa detta problem genom att använda oss av reinforcement 
learning

Programspråk, Utvecklingsmiljö
Vi kommer att bygga detta spel i VS code men köra det på processing. 
Vi tänkte bygga allt i .pde filer. Vi kommer att använda oss av github för 
att dela filerna mellan varandra så att vi alla kan sitta och programmera och 
jobba tillsammans på distans.
